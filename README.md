# 放疗科值班决策

**放疗 / 肿瘤科夜间值班 · 汇报决策核对单**（医学教育用途）

医学生第一次值班，最大的焦虑不是"不知道该做什么"，而是**不知道什么情况必须叫一线**——报错了顶多被说一句，该报没报要担责。

本工具把这件事做成一张 **30 秒能扫完的红线核对单**：

```
选场景 → 扫红线（有 / 无 / 未知）→ 出结论：立即汇报 / 建议汇报 / 可观察
```

## 功能

- **板块一 · 跟线汇报**：24 个肿瘤科场景红线核对（发热、血压低/休克、放射性损伤鉴别提示、免疫相关不良反应等）→ 结论 + 抢救处置步骤 + 医嘱模板（长期/临时）+ 报完之后四分支 + 病程记录草稿
- **板块二 · 值班措施**：15 条症状处置手册 + 6 张速查卡（抢救药物、危急值、电解质、输血、监测频次、记录书写规范），支持搜索与收藏
- **全点选零输入**：临床核对流程无任何输入框
- **离线可用**：单文件运行，无网络依赖
- **反馈闭环**：结论页一键反馈误报/漏报（离线暂存、联网自动补发）
- **检测更新**：App 内一键检查新版本

## 安装

从 [Releases](https://github.com/1099072409/rad-onc-duty/releases/latest) 下载 `放疗科值班决策-v*.apk` → 手机上直接安装（需允许"未知来源应用"）→ 装完完全离线可用。

## 声明（重要）

本工具**仅供医学教育与学习研究使用**，不是医疗器械，不构成任何医疗建议、诊疗依据或治疗方案。知识库中的红线、阈值、处置步骤与医嘱模板可能存在错误、遗漏或过时，均未经临床验证。任何临床决策必须由具备相应资质的医师依据现行诊疗规范独立作出。遇紧急情况请立即联系上级医师，切勿依赖本工具。
