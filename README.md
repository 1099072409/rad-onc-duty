# 要报一线吗？（跟班决策）

**Call the Senior? (On-Call Decision)** · 夜间值班 / 跟班决策核对单（Android + iOS）

医学生第一次值班，最大的焦虑不是"不知道该做什么"，而是**不知道什么情况必须叫一线**——报错了顶多被说一句，该报没报要担责。

本工具把这件事做成一张 **30 秒能扫完的红线核对单**：

```
第一步 看生命体征：平稳 / 不平稳
  ├─ 不平稳 → 体征清单按最急排序（立即 → 紧急 → 尽快），点一条直达核对单
  └─ 平稳   → 按主诉多选 / 按系统浏览选场景
之后：扫红线（勾选制：点一下 = 有，未勾 = 无）→ 出结论：初步诊断 + 针对性方案 + 立即汇报 / 建议汇报 / 可观察
```

## 功能

- **板块一 · 跟线汇报**：首页先分「生命体征平稳 / 不平稳」；不平稳时给出**按最急排序**的体征清单（呼吸 / 血压 / 血氧 / 脉搏可筛选），含义明确的条目直接出结论。共 **62 个场景**红线核对 → 结论（初步诊断 + 针对性方案）+ 立即处置 + 医嘱模板（长期 / 临时）+ 报完之后四分支 + 病程记录草稿；平稳时按主诉**多选**，自动合成个性化核对清单
- **板块二 · 值班措施**：**86 条**症状处置手册 + **71 张**速查卡（抢救药物、危急值、电解质、输血、监测频次、记录书写规范等），支持搜索与收藏
- **板块三 · 急救操作**：**13 条**床旁操作分步卡（CPR、除颤、气道、静脉通路等），含适应症、用物、常见错误，与板块一 / 二双向关联
- **诊断卡**：**933 张**全量卡片，每张含初步诊断、鉴别要点、处置步骤、医嘱与交接清单
- **设置中心**：300 套配色 × 100 套版面主题 × 100 套图标风格，可一键随机；字号 4 档；界面中 / 英双语；设置备份与恢复
- **全点选零输入**：临床核对流程无任何输入框
- **离线可用**：单文件运行，无网络依赖
- **反馈闭环**：结论页一键反馈误报 / 漏报（离线暂存、联网自动补发）
- **检测更新**：App 内一键检查新版本

## 安装

**Android**：从 [Releases](https://github.com/1099072409/rad-onc-duty/releases/latest) 下载 APK（文件 `Yaobaoyixianma-v*.apk`，页面显示「要报一线吗（跟班决策）（安卓下这个）」）→ 手机上直接安装（需允许"未知来源应用"）→ 装完完全离线可用。

**iOS / 平板 / 电脑**：下载 `Genbanjuece-ios.html`（页面显示「跟班决策（ios下载这个）」），用 Safari（或任意浏览器）打开即可，单文件离线运行，无需安装。
